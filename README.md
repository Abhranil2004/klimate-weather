# Klimate-weather

**Klimate** is a cutting-edge weather app designed to provide users with accurate, real-time weather updates. With its sleek design and intuitive interface, Klimate ensures you are always prepared for any weather conditions.

---

## Features
- 🌦️ **Real-Time Weather Updates**: Get instant weather information for your current location and saved cities.
- 📅 **5-Day Forecast**: Plan ahead with detailed forecasts.
- 🌃 **Dark Mode**: A soothing dark theme for low-light usage.
- 🌍 **Global Coverage**: Search weather information for any city worldwide.
- 🛠️ **Customizable Settings**: Switch between Celsius/Fahrenheit and manage default locations.

## Installation

1. **Download the APK**:
   - Visit the [Releases Page](#) to download the latest version of the app.

2. **Install the APK**:
   - Open the APK on your Android device and follow the prompts to install.

3. **Permissions Required**:
   - Location access for real-time weather updates.
   - Internet access for live data.

---

## How to Use

1. Open the app and allow location access.
2. View real-time weather for your location.
3. Use the search bar to look up weather for other cities.
4. Switch between light and dark mode in the settings.
